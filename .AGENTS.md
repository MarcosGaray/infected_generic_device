# Guía del proyecto

Simulador educativo sobre una red interna infectada en GPON. Este repositorio es público: todo el contenido debe ser genérico, ilustrativo y apto para cualquier empresa.

## Comandos

- `npm run dev`: servidor de desarrollo.
- `npm run build`: verificación TypeScript y build de producción en `dist/`.
- `npm run build:offline`: build + archivo único `dist/offline.html` para abrir sin servidor.
- `npm run preview`: vista previa del build.
- `npm run typecheck`: verificación TypeScript sin emitir.

## Estructura

- `src/data/`: contenido de diapositivas, flujo y simulación.
- `src/components/`: vistas de presentación, diagrama y simulador 3D.
- `src/styles/`: estilos globales y de módulos.
- `src/assets/`: fuentes y recursos genéricos.
- `public/`: archivos estáticos públicos.

## Reglas de contenido

- No incluir nombres de empresas, clientes, herramientas internas, proveedores, modelos de equipos, IPs, MACs, seriales ni capturas reales.
- Usar ejemplos genéricos y rangos ilustrativos.
- Mantener visible el aviso de contenido ilustrativo.
- No agregar credenciales, tokens ni archivos `.env`.
- La vista inicial debe ser la guía.
